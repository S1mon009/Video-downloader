# Utilities API

The `utils` package contains small reusable functions used by the application.

## Console

The console utility provides terminal-related functionality.

### `clear_console`

Clears the current terminal screen in a platform-aware way.

## Notifications

The notification utility provides notification cross-platform functionality.

### `send_notification`

Send notification to user with specific title and message.
